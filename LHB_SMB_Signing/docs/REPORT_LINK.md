# Chèn link vào báo cáo

Sau khi repository đã được tạo trên tài khoản GitHub của bạn, thay TEN_TAI_KHOAN bằng tên tài khoản thật:

https://github.com/TEN_TAI_KHOAN/LHB_SMB_Signing

Đoạn dùng trong báo cáo:

> Phần thực nghiệm kiểm chứng SMB Signing và CVE-2023-3347 do Lê Hoàng Bách (B23DCAT023) thực hiện được lưu tại: [dán URL repository thực tế]. Nội dung gồm chương trình kiểm chứng, hướng dẫn demo, cấu hình mẫu và minh chứng kết quả trước/sau vá. Các cấu hình thực tế và minh chứng bổ sung được mô tả theo trạng thái hiện có trong repository.

Thêm liên kết commit hoặc pull request do chính tài khoản của bạn tạo để thể hiện đóng góp cá nhân. Khi chốt, có thể dùng liên kết thư mục tại commit cụ thể để cố định phiên bản được dẫn.

## Đưa lên GitHub bằng trình duyệt

1. Đăng nhập tài khoản của chính bạn; chọn New repository.
2. Đặt tên LHB_SMB_Signing, thêm mô tả, chọn phạm vi hiển thị theo yêu cầu môn học.
3. Tạo repository, chọn Upload files và kéo toàn bộ nội dung bên trong thư mục LHB_SMB_Signing lên (không tải ZIP thay cho mã nguồn).
4. Nhập nội dung commit mô tả sản phẩm, rồi Commit changes.
5. Mở README kiểm tra ảnh và liên kết; lấy URL thật để đưa vào báo cáo.

Nếu nhóm đã có repository chung, đưa thư mục này vào repository nhóm bằng tài khoản của bạn và tạo commit/pull request riêng.
